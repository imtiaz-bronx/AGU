# Data & Codes Used in Our Research

A small, mobile-first website that goes with our AGU poster. Scan the QR code, tap a logo, and find where our data came from: NASA GPM IMERG, NOAA MRMS, NASA rain gauges, New York State, and our code on GitHub.

Built by [Imtiaz Mahmud](https://imtiazmahmud.com/) with [Dr. Yuri Gorokhovich](https://www.lehman.edu/academics/natural-social-sciences/earth-environment-geospatial-sciences/ac-gorokhovich/) in the [Department of Earth, Environment and Geospatial Science](https://www.lehman.edu/academics/natural-social-sciences/earth-environment-geospatial-sciences/) at [Lehman College, CUNY](https://www.lehman.edu/).

This work was funded by NASA. Thank you!

## Running it

It's plain HTML, CSS and JavaScript. Open `index.html` in a browser, or upload the folder to any web host.
